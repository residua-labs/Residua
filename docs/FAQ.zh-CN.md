# FAQ — 常见问题

[English](FAQ.md) | 中文

- **为什么用 Lean 子集？** 它是引导表面：编译器自身的源码就写在
  其中，Lean 的解析器与内核充当 oracle。它不是语言的最终设计。
- **Residua 依赖 Lean 吗？** 构建和运行 0.4 不需要 Lean。Lean 用于
  检查形式语义，并作为内核规则与解析器的参照。
- **为什么不直接用 Lean？** 就今天在一个工具里既编译又证明而言，
  Lean 更完备。Residua 的目标不同：结果跨工具、跨版本按内容识别，
  凭机械检查准入，以及一个你能从小[种子](GLOSSARY.zh-CN.md)复现的编译器。
- **为谁而做，由谁来建？** Residua 为 agent 而生、由 agent 所建：
  它由 AI agent 构建，每个变更由机械检查（差分门、植入变异体、
  不动点）与独立模型族的评审接受，绝不凭信任做出该变更的
  agent。
