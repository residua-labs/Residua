# 版本说明 — 带类型的内容地址（q 格式 v1）

[English](qformat-1.md) | 中文

状态：**随 0.3 版发货**；摘要另见 `docs/RELEASE-NOTES.zh-CN.md`。

## 提供的内容

树中每个内容身份现在把类别写进被哈希的字节：
`q(kind, c) = SHA-256("<kind> <len>\0" ++ c)`，即 git 对象头约定加版本化
类别注册表，打印为 `sha256:<hex>`（自描述二进制为 multihash
`0x12 0x20`）。原始 SHA-256 保留并更名为 `digest`，仅用于文件完整性
与互操作。两类不同的内容不再能共享同一个地址；未加标签格式实测到的
七处跨类别碰撞不可能再出现。

发布形式为 `docs/QFORMAT.md`（规范、版本 1 类别注册表、比较
规则、限制）。一致性检查为 `release/checks/qformat/`（六个向量与两个
植入对照，仅用 `sha256sum` 即可重算）。

  的字节，故不欠性能数据行。

## 限制

- `scc` 类别为保留；互递归组在规范成员顺序公布后才享有每组一个 q。
- 注册表为版本 1 且只增不改；类别的规范形式不在该类别下变化。
- 打印的 `sha256:` 字段由其模式定型，不自描述为 digest 或 q。
- 本目标对应的第三方验证任务（版本陌生者检查）：按
  `release/checks/qformat/README.md` 由类别与字节重算一个已发布的 q。
