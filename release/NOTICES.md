# NativeCert source provenance and retained notices

Source repository: https://github.com/leanprover/LNSym

Licence: Apache-2.0. The complete original text is retained in LNSym-LICENSE.
The upstream THIRD_PARTY_LICENSES file is retained verbatim as
LNSym-THIRD_PARTY_LICENSES; its ELFSage notice is not evidence that any
unmapped file is an ELFSage port.

The explicit Arm/Specs correspondence is declared in native-cert/NativeCert.lean
and native-cert/NOTES.md. FILES.tsv records all 86 tracked native-cert leaves,
their current SHA-256, and the exact upstream Git blob and SHA-256 where a
corresponding upstream file exists. Its comparison is observational: 3 byte
equal, 21 with only import-prefix changes, 37 modified ports. It does not assert
semantic equivalence of the 37 modified ports. Lean files remain repository-only
under the release manifest.

The other 25 files have no upstream counterpart in FILES.tsv. Six extend model
instruction families and nineteen are outside the explicit Arm/Specs
correspondence. Git history resolves their origin: each file's first-add
commit (`git log --diff-filter=A`) lies inside this repository
(0a5f3e3c32c81f536c9a3ec9a497b879754d4a19, 8e18a7d22e0c16e4cd094ebca2ca303369201bfd,
918dc3a2f9082a0a046ed6ec9e9b095ba6968e6e). They are listed individually in
PROVENANCE.tsv as residua-authored at that commit under the root Apache-2.0
licence, usage `repository-only`. No release-conformance claim is made beyond
that authorship and licence listing.
